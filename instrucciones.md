# Tarea: Investigación de lenguajes de programación

## Objetivo

Investigar información básica sobre diferentes lenguajes de programación y aprender a **buscar, comparar y verificar información en Internet**.

## Lenguajes a investigar

- Python
- Java
- C
- C++
- PHP
- Ruby
- FORTRAN / FORTRAN 90
- Pascal
- COBOL

## Fuentes de información

Para cada lenguaje consulte **registre las fuentes usadas**.

Registre:

- Nombre de la fuente.
- Enlace.


## Uso de Inteligencia Artificial

Puede utilizar herramientas como ChatGPT, Gemini o Copilot para orientarse.

Sin embargo:

> **La IA no será considerada una fuente de información.**

Los datos utilizados en el trabajo deben verificarse mediante páginas web, documentación oficial, universidades, organizaciones u otras fuentes confiables.

## Preguntas finales

Responda con sus propias palabras:

1. ¿Cuál es el lenguaje más antiguo de los investigados?
2. ¿Cuál es el lenguaje más reciente?
3. ¿Por qué cree que lenguajes antiguos como COBOL o FORTRAN todavía se utilizan?
4. ¿Cómo comprobó que la información encontrada era confiable?
